> **CN2 GIA 是线路组成的一部分，不等于所有中国运营商的所有路径都天然一样。**

## AS3、AN4、AN5 到底怎么区分

这三个名字不只是型号升级。

DMIT 当前官方给出的硬件定位是：

* **AN5：AMD EPYC 9005，Zen 5，DDR5，NVMe Gen5，偏向高流量网站、数据库和对延迟敏感的应用**
* **AN4：AMD EPYC 9004，Zen 4，定位更均衡，适合网站、应用和开发环境**
* **AS3：AMD EPYC 7003，Zen 3，官方把它放在更看重价格的项目、测试和入门部署上**

因此，不能简单理解成“AN5 一定值得买，AS3 就不行”。

假设你的服务是小型网站、个人项目、远程开发环境，甚至只是先部署一个对大陆用户比较友好的 API，AS3 TINY、Pocket 或 STARTER 已经具备 Premium 路由，没必要因为看到了“9005”就直接跳到 AN5。

反过来，如果业务本身对 CPU 计算、数据库负载或者大量并发请求比较敏感，AN5 的硬件平台显然更接近这类需求。官方也把 AN5 定位成当前性能更高的计算平台。

## 美国 CN2 GIA VPS 选购时，价格不是唯一变量

很多 VPS 对比文章喜欢把套餐按月价格排一遍，但这个关键词下，单纯比较价格很容易得出错误结论。

### 先看流量，再看端口

比如 AS3 TINY $10.90/月，看上去很便宜，但它只有 1000GB 月流量和 1Gbps 端口。

Pocket $16.90/月，流量是 1500GB，端口提高到 4Gbps。

STARTER $34.90/月，流量升到 3000GB，端口直接进入 10Gbps。

所以，真正应该问的是：**你的业务每个月实际需要多少流量？峰值访问是否依赖更高端口速率？**

一个很简单的博客、后台、监控节点和一个需要持续传输图片、文件、API 数据的站点，对 VPS 的要求完全不同。

### 再看 SSD 容量

存储也不能只看“SSD”三个字。

例如 AS3 MINI 和 MICRO 都是 4 vCore / 4GB，但 SSD 从 80GB 直接翻倍到 160GB，流量从 5TB 增加到 7TB。

如果你的主要问题是数据库、日志、Docker 镜像和网站媒体文件不断增长，MICRO 的空间差异可能比 CPU 变化更实际。

### 不要把“10Gbps”理解成“你的 VPS 一定能跑满 10Gbps”

这是一个很容易被忽略的点。

DMIT 的端口数字是产品层面的峰值能力。实际速度仍然受 VM 性能、国际网络、本地网络和具体路由影响。官方此前的活动说明也明确写过，VirtIO 端口速率属于峰值参考值，而不是实际带宽保证。

所以，看到“10Gbps”不应该自动理解为“从中国大陆单线程也能长期跑 10Gbps”。

对大多数站点来说，路由质量、RTT、丢包和高峰期稳定性往往比纸面端口数字更重要。

2. 在白天与晚高峰分别观察。

## 部署后怎么判断这台美国 CN2 GIA VPS 是否真的适合

拿到机器后，不需要马上迁移所有服务。

先做一轮小规模验证。

### 测延迟和丢包

至少测试你最重要的几个大陆网络节点，并在晚高峰重复测试。

如果白天 RTT 很漂亮，晚上突然飙高，而且丢包明显增加，那么产品页面上的线路名称也救不了你的业务。

### 测实际吞吐

用多线程测试和单线程测试分别看。

网站访问、API 调用和文件下载的瓶颈不一定相同。端口是 10Gbps，并不意味着单个 TCP 会话就能达到这个速度。

### 检查 IPv4 和 IPv6

DMIT 当前默认提供 IPv6 /64 前缀，但你是否真的需要 IPv6，要看应用和 DNS 配置。

如果服务器启用了 IPv6，而你的应用、CDN 或防火墙配置没有同步处理，就可能出现“IPv4 正常、IPv6 用户异常”的隐藏问题。

### 做备份和快照

DMIT 当前 Cloud Instance 产品强调快照和自动备份能力，同时提供 SSH Key 登录方式。

但“平台支持备份”不等于你已经有可恢复的数据。

## 常见问题

### 美国 CN2 GIA VPS 一定比普通美国 VPS 快吗？

对中国大陆方向的访问来说，专门优化的线路通常比没有针对性优化的普通路径更值得关注，但不能只靠线路名称判断实际速度。具体表现仍然取决于运营商、目标网络、时间和路由状态。DMIT 当前把 Premium 明确定位为中国大陆优化网络，而 Tier 1 则不包含中国专门路由增强。

### DMIT LAX Premium 是不是三网都走 CN2 GIA？

不应这样简单理解。官方当前说明是 Premium 使用中国电信 CN2 GIA，同时提供中国电信、中国联通和中国移动国际方向的专门互联。更准确的描述是“CN2 GIA + 三运营商方向优化互联”。

### AS3 和 AN5 的核心区别是什么？

AS3 是 AMD EPYC 7003，官方定位更偏成本敏感型和入门部署；AN5 使用 AMD EPYC 9005、DDR5 和 NVMe Gen5，定位更偏高性能场景。

### LAX AN4 还能买吗？

当前官方价格页显示 LAX AN4 Premium 的相关套餐为 Out of Stock，库存恢复时间需要以实时页面为准。

### DMIT 的美国 IP 能保证 Netflix、ChatGPT 等服务可用吗？

不能。DMIT 当前官方 IP 文档明确不保证特定网站、流媒体或服务的访问。

### 买哪一个配置比较合理？

先按业务需求算流量和内存，再决定硬件代际。一个月只消耗几百 GB 的轻量网站，没有必要因为看到 10Gbps 或 EPYC 9005 就直接买高阶套餐；相反，如果你跑的是数据库、高流量 API 或大型应用，应该优先看 RAM、CPU 和存储，而不是只看价格。
